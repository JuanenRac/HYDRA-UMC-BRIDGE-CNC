# Security Policy

Report authentication bypasses, unsafe state admission or a path that could
allow work while an E-STOP is asserted or a guard is open, privately to
electrohobby3d@gmail.com. Do not publish exploitable details before a fix is
available. This software is not a certified safety system and must never replace
independent emergency stop, guarding or safety-rated interlocks.
